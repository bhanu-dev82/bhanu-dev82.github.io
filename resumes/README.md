## Regeneration

All variants are produced by `generator/build_resumes.py`:

```bash
pip install reportlab
python3 resumes/generator/build_resumes.py
```

Edit the shared `data` model in that script (contact block, experience, projects,
publications, patents, awards) and rerun — every variant updates at once.
