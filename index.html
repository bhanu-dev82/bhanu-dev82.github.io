02 · case study

The Rote Playoffs study: procedure memory beats model effort.

For the WeMakeDevs × Modiqo hackathon I shipped 38 zero-key "Plays" (all scored 1.00, top-5 of 123 makers), then ran a controlled experiment: the same agent, model, and task — with a crystallized procedure versus re-deriving it from scratch. Frozen ground truth, deterministic grader, six tasks, leak audit, raw telemetry published.

The boundary is the finding: procedure memory adds nothing where the method is common knowledge — and is decisive everywhere else. Two baseline trials found the experiment's own answer key on disk; kept, reported, protocol amended. Full study with per-trial telemetry, grader, and paper:
